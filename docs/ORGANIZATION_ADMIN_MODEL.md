# ORGANIZATION ADMIN MODEL (v1)

## 목적
본 문서는 기관 관리자 기능의 계획 상태(v1)를 설명합니다.
현재 문서는 기능 출시 공지나 제공 완료 선언이 아닙니다.

## 현재 상태
- 기관 관리자 기능은 준비 중입니다.
- 교사 계정 중심 운영과 게스트 수업 흐름이 현재 기준입니다.
- 조직 단위 사용자/권한/프로비저닝 자동화는 정식 제공하지 않습니다.

## 계획 범위
- 기관 단위 권한 모델 초안
- 교사/학생/관리자 역할 분리
- 조직 설정 및 감사 로그 검토
- Workspace/로스터 연동 시 관리자 제어 연결 검토

## 비제공/주의
- SSO/자동 프로비저닝 제공 완료를 주장하지 않습니다.
- 대량 관리자 계정 발급/통합 관리 기능을 현재 제공한다고 안내하지 않습니다.
