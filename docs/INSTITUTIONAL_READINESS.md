# INSTITUTIONAL READINESS

## 등록 현황
곰도리는 에듀집 및 한국디지털교육협회에 학습지원 소프트웨어로 등록되어 있습니다.

## 허용 표현
- 에듀집 및 한국디지털교육협회에 학습지원 소프트웨어로 등록
- 기관 도입 자료를 단계적으로 준비 중
- 공식 템플릿은 개인정보 최소화 원칙을 따른다

## 표현 금지
- 인증 완료
- 보안감사 통과
- 교육청 승인
- 조달 등록 완료
- SLA 보장

## 준비 로드맵
1. 사업자등록번호 공개
2. 통신판매업 신고번호 공개
3. 공식 API 문서
4. 호스팅/SLA 정책
5. Google Workspace 연동 / 로스터 동기화
6. 외부 보안감사 또는 점검 증빙

## 기관용 데이터 처리/보안 문서(v1)
- `docs/DATA_HANDLING_AND_SECURITY.md`에서 학생 데이터 최소화, 게스트 접근 모델, 활동 데이터 저장 범위, 브라우저 기반 코드 실행 원칙, 삭제/보관 정책 현황, 로드맵을 공개합니다.
- 해당 문서는 인증/감사/SLA 보장 문서가 아니며, 현재 확인 가능한 사실만 기술합니다.

- `docs/SERVICE_OPERATIONS.md`에서 서비스 운영 원칙 v1, 장애 대응 흐름 초안, SLA 미보장 고지, 백업/복구 정책 준비 상태를 공개합니다.
