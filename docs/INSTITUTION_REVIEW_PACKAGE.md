# 기관 검토 자료 패키지 v1

## A. 문서 목적
이 문서는 학교·기관 검토자를 위한 **검토 자료 인덱스**입니다.
본 문서는 인증서, 조달 승인 문서, SLA 계약서, 외부 보안감사 보고서가 아닙니다.

## E. 현재 준비 중인 자료
- 사업자등록번호 공개
- 통신판매업 신고번호 공개
- 공식 문의 채널 정리
- 견적서/계약서 양식
- 세금계산서/결제 절차
- DPA/개인정보 처리 계약서
- 공식 SLA
- 상태 페이지
- 외부 보안감사/점검 자료
- Google Workspace/로스터 구현
- 조직 관리자 기능
- 공개 API 계약

## F. 표현 주의
허용 표현:
- 학습지원 소프트웨어 등록
- 기관 검토 자료 준비 중
- 공개 SLA 보장은 아직 제공하지 않음
- Workspace/로스터는 계획 문서 단계

검증 전 금지 표현:
- 공식 인증 완료
- 조달 승인
- 보안감사 통과
- SLA 보장
- Google Workspace 연동 완료
- 로스터 자동 동기화 제공
- 기관 관리자 기능 제공
- 세금계산서 발행 가능
- 계약 즉시 가능

- CSV 로스터 가져오기 계획 v1: `docs/CSV_ROSTER_IMPORT_PLAN.md`
- CSV 로스터 스키마 설계 v1: `docs/CSV_ROSTER_SCHEMA_DESIGN.md`
