# 도입 문의·견적·계약 준비 현황 v1

## A. 문서 목적
이 문서는 학교/기관이 곰도리 도입을 검토할 때 확인할 수 있는 자료와 문의 준비 항목을 안내합니다.
본 문서는 조달 승인, 계약 보장, 가격 확정 또는 견적 확약 문서가 아닙니다.

## B. 현재 도입 문의 상태
- 학교·기관 도입 문의는 현재 공개된 준비 자료를 바탕으로 단계적으로 대응합니다.
- 계약/견적/세금계산서/조달 관련 절차는 사업자 정보 및 운영 정책 정비 후 구체화할 예정입니다.
- 현재 확인 가능한 공개 문의 채널:
  - `/contact` (운영 문의 안내 페이지)
  - `/dashboard/billing/institution` (학교·기관 도입 문의 경로)
- 공식 도입 문의 채널의 단일화(전용 이메일/전화/티켓)는 준비 중입니다.

## D. 문의 시 제공하면 좋은 정보
도입 문의 시 아래 정보를 준비하면 검토가 수월합니다.

- 기관 유형(학교/교육기관/기타)
- 교사 수(대략)
- 학생 수(대략)
- 사용 목적(수업 유형/활동 시나리오)
- 필요한 개인정보/보안 검토 항목
- Google Workspace/로스터 연동 필요 여부
- 게스트 코드 기반 운영 vs 계정 기반 운영 선호
- 희망 파일럿 기간
- 견적/계약/세금계산서/조달 관련 문서 필요 여부

중요: 도입 문의 단계에서는 학생 개인식별정보(학생 실명, 전화번호, 주소, 주민등록번호 등)를 요청하지 않습니다.

## E. 현재 제공 가능한 것
- 기관 도입 안내 페이지(`/school`)와 기관 검토용 공개 문서
- 학습지원 소프트웨어 등록 현황 안내
- 개인정보 최소화 원칙이 반영된 공식 템플릿 가이드
- 브라우저 측 코드 실행 원칙(Web iframe sandbox, Python Pyodide Worker) 안내
- 교실 운영 시나리오 중심의 파일럿/도입 논의(문의 기반)

## F. 준비 중인 것
- 사업자등록번호 공개 표기 확정
- 통신판매업 신고번호 공개 표기 확정
- 견적서 양식
- 계약서/이용 신청서 양식
- 세금계산서 발행/처리 워크플로우
- 조달/학교 구매 검토 패키지
- DPA(개인정보 처리 계약) 문서
- 정식 SLA 문서
- 외부 보안감사/보안검토 증빙
- 기관 관리자 기능(organization admin)
- Google Workspace/로스터 동기화 정식 제공

## G. 표현 주의 사항
허용 표현:
- “도입 문의를 위한 자료를 준비 중입니다”
- “기관 검토용 문서를 단계적으로 공개하고 있습니다”
- “학습지원 소프트웨어로 등록되어 있습니다”

검증 전 금지 표현:
- “학교 납품 가능”
- “조달 등록 완료”
- “공식 인증 완료”
- “보안감사 통과”
- “SLA 보장”
- “세금계산서 발행 가능”
- “계약 즉시 가능”
