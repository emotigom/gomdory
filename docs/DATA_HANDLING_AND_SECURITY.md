# DATA HANDLING AND SECURITY (v1)

## A. 목적
곰도리는 교실 수업 지원 및 학습 활동 운영을 위한 플랫폼입니다.
이 문서는 학교/기관 검토를 위해 현재 데이터 처리·보안 운영 상태를 요약한 v1 문서입니다.
본 문서는 인증서, 외부 보안감사 보고서, 조달 승인 문서, SLA 보장 문서가 아닙니다.

## B. 학생 개인정보 최소화 원칙
공식 수업 템플릿/스타터 예시는 다음 직접 식별 정보를 요구하지 않도록 설계합니다.

- 학생 실명
- 학교명
- 전화번호
- 주소
- 이메일
- 생년월일
- 학번
- 주민등록번호/국가식별번호
- 건강정보 등 민감정보

공식 템플릿은 다음과 같은 비식별 예시를 사용합니다.

- 닉네임
- 가상 팀명
- 가상 상황/예시
- 비식별 활동 응답

## C. 계정 및 게스트 접근 모델
현재 동작 기준:

- 교사/보드 소유자는 인증 계정으로 수업을 운영합니다.
- 학생은 보드 설정/권한에 따라 QR 또는 공유 코드 기반 게스트 참여가 가능합니다.
- 게스트 모드는 관리자/파괴적 작업을 제한합니다.
- 게스트는 허용된 보드 권한 범위에서 활동 상태/콘텐츠를 생성할 수 있습니다.
- 게스트는 보드 설정 변경 및 소유자 핵심 콘텐츠 삭제 권한이 없습니다.

## D. 저장 가능한 학습 활동 데이터
수업 운영 과정에서 다음 데이터가 저장될 수 있습니다.

- 보드 카드 데이터
- 업로드 첨부 메타데이터
- 수업 활동 실행 정보
- AI Bingo 선택/이유
- AI Judgment Sort 분류/이유
- Web Studio HTML/CSS/JS 코드 상태
- Python Studio code/stdin/stdout/stderr 상태
- 제출 상태/타임스탬프
- anonymous/guest participant key hash

참고:
완전한 익명성을 보장한다고 단정하지 않습니다. 세션/활동 맥락과 결합되면 참여 상태가 연결될 수 있습니다.

## E. 코드 실행 안전성
현재 코드 실행 원칙:

- Web Studio는 브라우저 iframe sandbox에서 HTML/CSS/JS를 실행합니다.
- iframe은 `sandbox="allow-scripts"`를 사용하며 `allow-same-origin`은 부여하지 않습니다.
- Python Studio는 브라우저 측 Pyodide Worker 기반으로 동작합니다.
- 학생 코드는 서버에서 실행하지 않습니다(서버사이드 학생 코드 실행 없음).
- 패키지 설치 기능은 제공하지 않습니다.
- 외부 코드 실행 서비스는 사용하지 않습니다.
- 알려진 제한: 무한 루프 등은 브라우저 런타임에 영향을 줄 수 있으며, 구현된 범위에서 timeout/worker 종료로 완화합니다.

## F. 외부 AI / LLM 사용
현재 기준:

- Web Studio Hint Coach는 결정론적/로컬 규칙 기반입니다.
- 학생 코드를 외부 AI 서비스로 전송하지 않습니다.
- 향후 LLM 기반 힌트를 도입할 경우, 교사 통제 옵션과 별도 문서화를 전제로 검토합니다.

## G. 저장소/호스팅 및 인프라
현재 저장소/호스팅 구성은 프로젝트 설정을 기준으로 운영되며, 기관 제출용 인프라 세부 문서는 준비 중입니다.
리포지토리와 문서에서 확인 가능한 범위만 공개하며, 벤더 보장/인증 효력을 임의로 주장하지 않습니다.

## H. 데이터 보관/삭제
정식 보관/삭제 기간 정책은 준비 중입니다.

현재 확인 가능한 운영 동작:

- 보드 소유자는 보드/콘텐츠 삭제 작업을 수행할 수 있습니다.
- 교사는 수업 카드/첨부를 관리(수정/삭제)할 수 있습니다.
- 활동 데이터 정리 정책은 보드/세션 수명주기 기준으로 정리 중입니다.
- 내보내기(export) 및 표준화된 보관 기간 정책 문서는 준비 중입니다.

## I. 현재 구현된 보안 실무
현재 코드/테스트에서 확인 가능한 범위:

- 서버측 권한 검사
- 교사/게스트 권한 분리
- participant key hashing
- 공유 코드 검증
- 보드 역할 기반 접근 제어
- iframe sandbox 격리
- 서버사이드 학생 코드 실행 미사용
- 공식 템플릿 개인정보 가드 테스트
- 라우트 입력 검증
