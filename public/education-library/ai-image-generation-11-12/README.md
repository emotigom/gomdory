# 11~12차시 이미지 생성 AI 이론

The HTML presentation bundle for `ai-image-generation-11-12` is published from the Cloudflare R2 public assets bucket.

Public URL:

```text
https://assets.gomdory.com/education-library/ai-image-generation-11-12/index.html
```

`gom-public-assets` is the bucket name, not a URL path segment. Do not include `/gom-public-assets/` or `/public/` in public URLs.

Browsers may automatically request `/favicon.ico` from `assets.gomdory.com` when this standalone HTML presentation opens. To keep the console clean, upload the shared root `favicon.ico` described in `public/education-library/README.md` to the `gom-public-assets` R2 bucket root.

The registry entry is defined in `lib/education/lessonLibraryRegistry.ts`, and `/learn/ai-image-generation-11-12` redirects to the R2 public URL when the resource is published.
